# أداة الفحص التشخيصي للجهاز (Device Diagnostic Tool)

مشروع ويب تشخيصي متكامل مصمم للنشر السحابي على منصة Netlify، ويعتمد على Netlify Functions للتواصل الآمن مع Telegram Bot API دون كشف الأسرار البرمجية في كود الواجهة.

---

## 1. الفكرة والهدف الأكاديمي
- **المفهوم البرمجي:** فحص وتدقيق خصائص النظام والمتصفح من جانب العميل (Client-Side Diagnostics) لتقييم ما يُعرف بـ *بصمة المتصفح (Browser Fingerprinting)*.
- **الأخلاقيات والخصوصية:** التطبيق ملتزم بالشفافية الكاملة؛ حيث يتم إشعار المستخدم بالبيانات المستخرجة وعرضها أمامه، مع اشتراط موافقته الصريحة قبل نقل أي تقرير، وجعل مشاركة الموقع الجغرافي اختيارية بالكامل.
- **الحماية والأمان:** عدم تضمين توكن تيليجرام أو معرّف المحادثة داخل كود المتصفح إطلاقاً، وتمرير البيانات عبر خادم وسيط (Serverless Function) يقرأ البيانات الحساسة من متغيرات البيئة.
